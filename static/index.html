Limitations

What this score is not.

Labels

Reported, not proven

Labels come from historical reports of scam activity: noisy, incomplete, and skewed toward addresses someone bothered to report.

Time

No timestamps

The dataset carries no timestamps, so the train/test split is stratified at random. It is not time-aware.

Coverage

Demo dataset only

Only the addresses in the public Ethereum Fraud Detection dataset can be scored. Anything else returns a clear not-found.

Disclaimer

Risk scores describe patterns in publicly reported data. They are not an accusation and not financial advice.
